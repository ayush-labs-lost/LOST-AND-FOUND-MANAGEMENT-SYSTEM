# Project Statement

## Problem Statement

Students may lose or find personal belongings on campus, but there may not be a simple system to record and manage these items.

This project provides a simple digital system for recording lost and found items and helping users search and recover them.

## Scope

The project is designed for managing lost and found items in a college or campus environment.

## Target Users

- College students
- Faculty members
- College staff

## High-Level Features

- Report lost items
- Report found items
- Search items
- View items
- Claim recovered items
- Remove items
- View statistics
- Data storage
