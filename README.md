# Lost & Found Management System

## Overview

The Lost & Found Management System is a Python-based project designed to help users report, search, manage, and recover lost and found items.

## Features

- Report Lost Item
- Report Found Item
- Search Items
- View Lost Items
- View Found Items
- Claim / Recover Item
- Remove Item
- View Statistics
- Save and Load Data using JSON

## Technologies Used

- Python
- JSON
- VS Code

## How to Run

1. Install Python.
2. Open the project folder in VS Code.
3. Open the terminal.
4. Run:

```text
python lost_found.py
